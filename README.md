
# MoneyLab

Personal Financial Planning & Decision Simulator

## Overview

MoneyLab is a Python application that helps users analyze
monthly cash flow, calculate debt repayment, and project
their future financial position.

## Technology

- Python
- Streamlit
- Pandas
- Pytest

## Development Status

Phase 1: In Progress

## Running the Application

Install dependencies:

    python -m pip install -r requirements.txt

Launch Streamlit:

    python -m streamlit run app.py
